**API's**

For creation of new Admin and Authorization with "Bearer MASTER_JWT"
POST http://localhost:5000/api/master/admins
JSON body:
    {
        "name": "DBMS Admin",
        "email": "dbms.admin@campusnotes.com",
        "password": "Dbms@123"
    }

For Giving Permissions to the Admin and Authorization with "Bearer MASTER_JWT",
Replace ADMIN_ID with the real one.

PUT http://localhost:5000/api/master/admins/ADMIN_ID/permissions

JSON body:
        {
            "approveNotes": true,
            "rejectNotes": true,
            "deleteNotes": false,
            "editContent": true,
            "manageSubjects": false,
            "disableUsers": false,
            "viewStatistics": true
        }

For Assign Subjects to admins: here Replace ADMIN_ID with the real one.

    {
